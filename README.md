###  Featured Projects

####  [Drone Pathika](https://github.com/Harsh4211/drone.pathika) · [Live Demo](https://harsh4211.github.io/drone.pathika)
A browser-based drone mission planner and flight simulator, built with vanilla JavaScript and no backend.
- Click-to-plan waypoints on an interactive Leaflet map with live distance, ETA, and battery estimates
- Live telemetry dashboard (altitude, speed, battery, heading) with real-time charts
- Real-time wind and weather from Open-Meteo, with wind-friction physics applied to the flight
- No-fly zone detection based on DGCA regulations, plus a responsive layout for desktop, tablet, and mobile

`JavaScript` `Leaflet.js` `Chart.js` `Open-Meteo API`

####  [AI-Based Military Intelligence Dashboard](https://github.com/Harsh4211/Military_Intelligence_Dashboard)
A Streamlit intelligence platform built on the Global Terrorism Database (200,000+ incidents).
- Interactive global threat map and country-level analysis
- Random Forest model for attack type prediction, with confidence scores
- Threat level classification and multi-year trend forecasting
- Auto-generated intelligence reports and an advanced data explorer with CSV export

`Python` `Streamlit` `Scikit-learn` `Plotly` `Pandas`
